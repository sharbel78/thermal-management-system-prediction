🌡️ Thermal Management System Prediction using Machine Learning
📌 Overview

This project focuses on predicting temperature behavior in a Thermal Management System (TMS) using Machine Learning techniques.
Thermal management is critical in systems like electric vehicles (EVs), batteries, and electronics to ensure safety, efficiency, and performance.

🎯 Objective
Predict temperature values using ML models
Classify system performance conditions
Analyze factors affecting thermal behavior
🚀 Features
📊 Data preprocessing (scaling, encoding)
🤖 Machine Learning models:
Random Forest Classifier
Gradient Boosting Regressor
📈 Performance evaluation:
Accuracy Score
Mean Squared Error (MSE)
📉 Data visualization
⚡ Optional Streamlit web app interface
🛠️ Tech Stack
Python
Scikit-learn
Pandas
NumPy
Matplotlib / Seaborn
Streamlit (for UI)
